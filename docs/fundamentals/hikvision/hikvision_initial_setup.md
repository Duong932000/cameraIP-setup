# Hikvision Initial Setup

This document describes the initial setup process for a Hikvision IP camera on Linux or local network.

Target camera:
- Hikvision DS-2CD2046G2H-I2U/S(L)(RB)

# Required Hardware

## Camera

Hikvision IP camera

## Ethernet Cable

Recommended: CAT6

## Network Device

One of:
- Router
- Network switch
- PoE switch

## Power Supply

The camera can be powered by:
- PoE
OR
- 12V DC adapter
